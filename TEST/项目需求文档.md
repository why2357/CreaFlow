# 图片管理系统 - 需求文档

## 项目概述

基于 Vue 3 + Vite + TypeScript 开发的图片管理系统，支持图片上传、分类管理和文本混排编辑。

## 技术栈

- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **语言**: TypeScript
- **样式**: CSS (Scoped)

## 功能需求

### 1. 项目初始化

创建 Vue 3 + Vite + TypeScript 项目脚手架。

### 2. 基础界面

- 输入框：用于输入文本内容
- 上传图片按钮：支持选择图片文件

### 3. 图片上传功能

- 支持多图片同时上传
- 支持常见图片格式（image/\*）
- 上传后显示图片预览

### 4. 图片分类管理

**预置分类**：

- 风景
- 人物
- 动物
- 其他

**功能**：

- 每张图片可单独设置分类
- 图片按分类分组展示
- 显示每个分类下的图片数量
- 可修改图片所属分类
- 可删除图片

### 5. 图片提及功能

**功能描述**：在输入框中插入图片缩略图

**触发方式**：

1. 在输入框中输入 `@` 符号，弹出图片选择菜单
2. 直接点击图片卡片上的 `@` 按钮

**插入效果**：

- 图片直接插入到输入框的光标位置
- 图片高度与文字行高一致（1.2em）
- 图片与文字可自然混排

### 6. 图片拖拽排序

**功能描述**：在输入框中拖拽图片调整位置

**支持的操作**：

- 图片与图片之间交换位置
- 图片拖拽插入到文字中间任意位置
- 图片拖拽到文字开头或结尾

**交互效果**：

- 鼠标悬停图片时显示抓取光标（grab）
- 拖拽时图片半透明显示
- 拖拽到图片上：目标位置显示绿色光标指示器
- 拖拽到文字上：使用光标位置指示插入点
- 光标指示器闪烁效果，提示用户插入位置
- 绿色竖线显示在目标图片左侧或右侧
- 松开鼠标完成位置交换/插入

**视觉反馈**：

```
图片交换：
拖拽前：[图片1] [图片2] [图片3]
拖拽图片2到图片1前：│ [图片1] [图片2] [图片3]
                  ↑ 绿色闪烁光标
完成交换：[图片2] [图片1] [图片3]

插入文字：
拖拽前：这是一段文字内容
拖拽图片到文字中：这是一段│文字内容
                  ↑ 插入位置
完成插入：这是一段[图]文字内容
```

### 7. 内容预览

- 实时显示输入框中的内容（文字+图片）
- 图片保持与输入框相同的尺寸样式

## 操作流程

### 上传图片

1. 点击「+ 上传图片」按钮
2. 选择一张或多张图片
3. 图片自动上传并归类到「其他」

### 分类管理

1. 在图片卡片下拉框中选择目标分类
2. 图片自动移动到对应分类组

### 插入图片到文本

**方式一**：

1. 在输入框中输入 `@`
2. 从弹出菜单中选择图片

**方式二**：

1. 点击图片卡片上的 `@` 按钮
2. 图片自动插入到输入框

### 调整图片顺序

**图片与图片交换**：

1. 鼠标按住输入框中的图片
2. 拖动到另一张图片的左侧或右侧（观察绿色光标指示器）
3. 松开鼠标完成交换

**图片插入文字中**：

1. 鼠标按住输入框中的图片
2. 拖动到文字中间的任意位置
3. 松开鼠标，图片插入到该位置

## 开发命令

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```
