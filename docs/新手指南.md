# 新手上手指南 - 创流 (Forge HiVision)

## 项目概述

**创流 (Forge HiVision)** 是一个基于 Vue 3 + TypeScript + Element Plus + Vite 构建的视频生产工作台平台。这是一个多租户
SaaS 平台，用于通过结构化工作流创建 AI 生成的视频内容。

## 一、项目启动与环境配置

### 1.1 环境要求

- **Node.js 版本**: v16
- **包管理器**: npm
- **默认开发端口**: 80

### 1.2 启动步骤

```bash
# 安装依赖（使用国内镜像）
npm install --registry=https://registry.npmmirror.com

# 启动开发服务器
npm run dev

# 生产环境构建
npm run build:prod

# 代码检查和修复
npm run lint

# 代码格式化
npm run prettier
```

### 1.3 代理配置

开发服务器默认代理后端 API 到: `http://172.28.44.150:16020`

配置文件: [vite.config.ts](vite.config.ts)

### 2.2 关键架构模式

#### API 层模式

每个 API 领域包含两个文件：

- **index.ts** - 使用 `@/utils/request` 的 axios 实例发起请求
- **types.ts** - 请求和响应的 TypeScript 类型/接口定义

#### Store 模式

Pinia stores 位于 `src/store/modules/`，按功能组织：

- app - 应用全局状态
- user - 用户信息
- permission - 权限管理
- project - 项目状态
- dict - 字典数据

#### 路由结构

- **常量路由** - 公开页面（登录、首页、404 等）
- **动态路由** - 基于后端返回的用户权限加载
- 路由支持 meta 属性用于权限控制、缓存和导航控制

## 三、核心功能

### 3.1 项目创建工作流

核心功能是位于 [src/views/workbench/project-creation/](src/views/workbench/project-creation/) 的 5 步工作流：

| 步骤 | 组件          | 功能               |
| ---- | ------------- | ------------------ |
| 1    | StepCharacter | 上传角色参考图片   |
| 2    | StepScene     | 上传场景参考图片   |
| 3    | StepScript    | 根据提示词生成脚本 |
| 4    | StepShotList  | 审查/编辑分镜      |
| 5    | StepGridView  | 生成图片的网格预览 |
| 6    | StepVideo     | 从分镜生成最终视频 |

### 3.2 实时通信 (SSE)

**SSE (Server-Sent Events)** 用于 AI 内容生成期间的实时更新：

| 文件                                                                   | 作用                       |
| ---------------------------------------------------------------------- | -------------------------- |
| [src/utils/sse.ts](src/utils/sse.ts)                                   | SSE 连接管理，支持自动重连 |
| [src/utils/sseTabCoordinator.ts](src/utils/sseTabCoordinator.ts)       | 跨浏览器标签页的 SSE 协调  |
| [src/composables/useSSEListener.ts](src/composables/useSSEListener.ts) | Vue 3 SSE 事件监听钩子     |

**消息类型**：

- `messageType=1`: 脚本生成完成
- `messageType=2`: 图片生成更新
- `messageType=3`: 视频生成更新

**自定义事件**：SSE 消息作为 window 事件派发：

- `sse-script-update`
- `sse-image-update`
- `sse-video-update`

## 四、技术栈详解

### 4.1 自动导入配置

**Vue APIs**: 自动从 `vue`、`vue-router`、`pinia`、`@vueuse/core` 导入

- 配置文件: [vite/plugins/auto-import.ts](vite/plugins/auto-import.ts)

**Element Plus 组件**: 通过 `unplugin-vue-components` 和 ElementPlusResolver 自动导入

**Element Plus APIs**: ElMessage、ElMessageBox 等自动导入

**图标**: `src/assets/icons/svg/` 中的 SVG 图标已注册，可通过 SvgIcon 组件使用

### 4.2 请求/响应处理

**Axios 配置** ([src/utils/request.ts](src/utils/request.ts))：

| 配置项   | 说明                                       |
| -------- | ------------------------------------------ |
| Base URL | 从环境变量 `VITE_APP_BASE_API` 读取        |
| 认证     | `Authorization: Bearer ${token}` JWT token |
| 加密     | 支持 AES + RSA 混合加密                    |
| 401 处理 | 自动处理并提示重新登录                     |
| 防重放   | 500ms 间隔内的重复请求会被阻止             |

**响应处理**：

- 成功响应: `code === 200`
- 自定义错误码: [src/utils/errorCode.ts](src/utils/errorCode.ts)
- 下载操作支持 Loading 状态

### 4.3 权限系统

| 类型     | 实现                                |
| -------- | ----------------------------------- |
| 路由权限 | 动态路由根据后端权限过滤            |
| 指令权限 | `v-hasPermi` 指令用于元素级权限控制 |
| 项目权限 | 用于基于项目访问控制的额外权限系统  |

### 4.4 国际化支持

- 翻译文件位置: [src/lang/](src/lang/)（zh_CN、en_US）
- 使用方式: `useI18n()` composable 或模板中的 `$t()`
- 语言设置: 存储在 localStorage 的 `language` 字段

### 4.5 环境变量

| 变量                  | 说明                      |
| --------------------- | ------------------------- |
| VITE_APP_BASE_API     | 后端 API 基础路径         |
| VITE_APP_CLIENT_ID    | OAuth 客户端 ID           |
| VITE_APP_CONTEXT_PATH | 部署上下文路径            |
| VITE_APP_PORT         | 开发服务器端口（默认 80） |

## 六、实战建议

### 6.1 上手步骤

1. **先用起来** - 在开发环境完整操作一遍所有功能
2. **断点调试** - 在关键流程打断点，理解数据流转
3. **看网络请求** - 浏览器开发者工具看 API 调用
4. **从改小需求开始** - 比如改文案、调整样式
5. **善用搜索** - 用关键词在代码库搜索找到相关代码

### 6.2 调试技巧

| 技巧            | 说明                           |
| --------------- | ------------------------------ |
| 浏览器 DevTools | 查看 Network 面板了解 API 调用 |

## 七、常见问题

### Q1: 端口 80 被占用怎么办？

修改 `vite.config.ts` 中的 `server.port` 配置，或使用管理员权限运行。

### Q2: 如何添加新页面？

1. 在 [src/views/](src/views/) 创建页面组件
2. 在 [src/router/index.ts](src/router/index.ts) 添加路由配置
3. 如需权限控制，在 meta 中配置

### Q3: 如何调用后端 API？

1. 在对应 domain 的 [src/api/[domain]/types.ts](src/api/) 定义类型
2. 在 [src/api/[domain]/index.ts](src/api/) 编写请求函数
3. 在组件中导入并调用

### Q4: SSE 消息如何监听？

```typescript
import { useSSEListener } from '@/composables/useSSEListener';

const { startListening, stopListening } = useSSEListener();

onMounted(() => {
  startListening();
});

onUnmounted(() => {
  stopListening();
});
```
